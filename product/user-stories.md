# User stories

## Player/modder help

As a player or modder, I want to ask "I'm crashing here, what do I do?" and receive practical troubleshooting steps based on known community reports.

Acceptance:

- Returns steps, confidence, and one follow-up question if needed.
- Shows sources used.
- Does not expose private evidence unnecessarily.

## Community correlation

As a community manager, I want to ask "Anyone else seeing this bottleneck?" and receive prevalence, affected setups, and likely causes.

Acceptance:

- Searches connected sources only.
- Ranks by recency and confirmations.
- Distinguishes widespread issue from isolated complaint.

## Draft reply

As a moderator, I want a calm reply drafted for a heated thread.

Acceptance:

- Fetches thread context.
- Drafts helpful response.
- Queues for approval.
- Does not post automatically.

## Idea pull

As a developer, I want repeated complaints converted into ranked idea cards.

Acceptance:

- Clusters repeated asks.
- Links evidence.
- Suggests a poll or RFC.

## Extension usage

As a dev or modder, I want to use this inside the browser and code editor.

Acceptance:

- Browser extension reads visible/selected page context only after user action.
- VS Code extension reads selected text/logs only by default.
- Local actions require approval.
