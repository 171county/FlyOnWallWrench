# Scope

## In scope

- Community help questions
- Community search
- Evidence-backed answers
- Draft replies and announcements
- Poll and FAQ drafts
- Known issue summaries
- Idea extraction
- Approval queue
- Browser extension companion
- VS Code extension companion
- User-selected AI provider
- Ephemeral evidence handling

## Out of scope

- Mod file hosting
- Mod metadata database
- Dependency graphs
- Release artifact management
- Game build pipelines
- Browser/computer/IDE control by MCP
- Automatic public posting
- Automatic moderation
- Sensitive data storage by the MCP
