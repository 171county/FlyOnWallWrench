# Communication source stack

This repo is for communication surfaces only.

## Core v1

### Discord

Live help, forum channels, support threads, announcements, feedback, moderation escalations.

### Reddit

Public sentiment, issue discovery, player questions, launch reactions, wishlists.

### Steam reviews/news/discussions where supported

Player reviews, patch reaction, public update context, and discussions where access is compliant.

### Forums

Long-form support, official community conversations, bug reports, searchable FAQs.

### GitHub Discussions/issues/comments

Technical community communication for open-source mods, tools, SDKs, loaders, and dev communities.

## Follow-on

### YouTube

Trailer/update comments, tutorial feedback, creator reaction, devlog comments, live chat.

### Twitch

Dev streams, creator playtests, live event feedback.

### Slack and Matrix

Internal team routing and private contributor communities.

### App store reviews

Mobile game reviews and developer responses.

### Social and helpdesk

Public social listening and structured support workflows for larger teams.

## Explicit non-scope

This repo should not become a mod database, file manager, dependency graph, release manager, or large suite metadata connector.
