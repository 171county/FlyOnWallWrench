# Web app design

## Purpose

The web app is the operations hub for Help Me Comms.

## Main sections

### Help Me Inbox

Incoming questions, noisy threads, support requests, and community spikes.

### Evidence viewer

Shows sources used, evidence snippets, links, confidence, and redaction status.

### Drafts and approval queue

Shows replies, announcements, polls, FAQ drafts, known-issue posts, and triage cards waiting for user action.

### Known issues

Clusters repeated help requests and confirmed problems.

### Idea board

Pulls feature requests, QoL requests, pain points, and community proposals into ranked idea cards.

### Source settings

Connect and scope sources. Configure read/write settings and approved spaces.

### Provider settings

Select AI provider, model, budget limits, data-sending rules, and local mode.

### Privacy settings

Configure retention, redaction, user-owned storage, audit metadata, and source revocation.

## UI trust language

Use clear language:

- "This will read only approved channels."
- "This draft will not be posted until you approve it."
- "This evidence is temporary and will be discarded after the task."
- "This source is available but not enabled for this workspace."
